# Pre-AO-1990 European Portuguese orthography reference

This reference enumerates the orthographic differences between the pre-1990 and post-1990 conventions that most frequently arise in astrophysics, cosmology, and physics lesson summaries. Consult it whenever uncertain whether a word retained or lost a silent consonant.

## The core rule

The 1990 Acordo Ortográfico suppressed silent consonants (most commonly `c` and `p`) that were no longer pronounced. The pre-1990 convention preserves them. When generating a lesson summary, ALWAYS use the pre-1990 form.

## Verbs whose conjugations cascade

When a base verb retains its silent consonant, every conjugated form does too. The most consequential in scientific prose:

- `activar` → `activa`, `activam`, `activada`, `activação`
- `actuar` → `actua`, `actuam`, `actuação`
- `adoptar` → `adopta`, `adoptam`, `adoptado`, `adopção`
- `corrigir` → unchanged across reforms
- `dirigir` → unchanged across reforms
- `efectuar` → `efectua`, `efectuam`, `efectuação`
- `inspeccionar` → `inspecciona`, `inspecção`
- `interagir` → unchanged across reforms
- `projectar` → `projecta`, `projectam`, `projecção`, `projecto`
- `reflectir` → `reflecte`, `reflectem`, `reflexão` (note: `reflexão` is unchanged, with `x`)
- `seleccionar` → `selecciona`, `selecção`

## Diaeresis

The pre-1990 convention preserved the diaeresis in a small number of words to mark a vowel that would otherwise be silent. In modern technical prose this is rarely required, but if it arises, prefer the diaeresis form. The 1990 reform abolished it almost entirely.

- `argüir`, `argüição` (pre-1990) vs `arguir`, `arguição` (post-1990)
- `lingüista`, `lingüística` (pre-1990) vs `linguista`, `linguística` (post-1990)

In astrophysical prose these are rare; default to whichever form you most commonly find in the user's exemplar files.

## When in doubt

If a word does not appear in this table and you are uncertain, prefer the form with the consonant preserved. Over-application of the pre-1990 convention is a venial fault; under-application is a cardinal one, because it betrays the entire stylistic register the user has demanded.
